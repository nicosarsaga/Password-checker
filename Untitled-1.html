REFERENCE

Security Guide

Concepts demonstrated by the system.

01

Brute Force Attack

An attacker systematically attempts possible passwords until a valid credential is discovered.

02

Dictionary Attack

An attacker uses lists of common words, passwords and predictable combinations.

03

Credential Stuffing

Previously leaked username/password combinations are tested against other services.

04

Password Hashing

Password storage systems should use dedicated password-hashing algorithms rather than storing plaintext passwords.

05

Multi-Factor Authentication

MFA adds another authentication factor beyond the password.

06

Password Manager

Password managers can generate and securely store unique credentials for different services.
